# Lexicon — IELTS Vocabulary Studio

A small, browser-based vocabulary app for IELTS learners aiming for band 8.5.

## Run it

Open `index.html` in a modern browser. No install or build step is needed. Learning progress and saved vocabulary are stored in that browser on that device.

## Study collections

- Environment
- Education
- Technology
- Health
- Society
- Economy & work
- Cities & transport
- Academic vocabulary

Each item includes a definition, usage note, and IELTS-style example. The study cards support reveal, save, previous, need-review, and got-it actions. Use the topic navigation or search to explore the vocabulary library.

The seven topic-based collections contain 30 items each. Academic Vocabulary contains 110 terms across eight subject areas and an Academic Foundations set, for 320 items total.

The **Academic vocabulary** learning path has its own entry in the main navigation. It groups terms into Philosophy, Archaeology, Anthropology & Culture, History, Psychology, Sociology, Biology & Ecology, Geology & Earth Science, and Academic Foundations. Select a set to study its flashcards or browse its word list; study all 110 terms together when preferred.

## Academic vocabulary sources

The app includes an in-page source guide with links to:

- [IELTS Writing preparation resources](https://ielts.org/take-a-test/preparation-resources/writing-test-resources), for the official Lexical Resource assessment guidance.
- [British Council: Vocabulary for IELTS](https://takeielts.britishcouncil.org/blog/vocabulary-for-ielts), for learner strategies and practice advice.
- [Victoria University of Wellington: How to use the Academic Word List](https://www.wgtn.ac.nz/lals/resources/academicwordlist/information/howto), for guidance on using the research-based list.

IELTS assesses vocabulary range, precision, accuracy, and appropriacy; word lists work best as practice references alongside contextual use. The app’s academic collection is curated for IELTS practice; its definitions, usage notes, and example sentences are original learner materials, not official IELTS content.
