# Lexicon — IELTS Vocabulary Studio

A small, browser-based vocabulary app for IELTS learners aiming for band 8.5.

## Run it

Open `index.html` in a modern browser. No install or build step is needed. Learning progress and saved vocabulary are stored in that browser on that device.

## Study collections

- Environment
- Education
- Technology
- Health
- Society
- Economy & work
- Cities & transport
- Specialised academic vocabulary

Each item includes a definition, usage note, and IELTS-style example. The study cards support reveal, save, previous, need-review, and got-it actions. Use the topic navigation or search to explore the vocabulary library.

Each of the eight collections contains 30 items (240 total), including 30 entries in Specialised Academic Vocabulary.
