# Project instructions

## Verify the target before editing

- Before changing files, confirm the exact working folder and inspect its contents.
- Treat requests to create a new app or project as separate work in the current folder. Do not modify a neighboring or existing app unless the user explicitly asks for that.
- If the intended target is unclear, ask before editing files outside the current folder.
- Keep all changes within the confirmed target and check the changed-file list before finishing.
